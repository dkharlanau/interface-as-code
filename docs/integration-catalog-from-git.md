# Build an enterprise integration catalog from Git

A useful integration catalog should be generated from validated source, not maintained as a second manually synchronized spreadsheet. `interface-as-code catalog` creates a searchable static HTML catalog, machine-readable JSON index, per-interface pages and a system topology graph. Filters cover protocol, criticality, lifecycle and owner; free-text search covers IDs, systems and business metadata.

The same index can feed Backstage/LeanIX adapters or the read-only MCP server.
