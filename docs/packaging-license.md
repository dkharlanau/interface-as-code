# Package license metadata

`LicenseRef-Interface-As-Code` refers to the complete bundled `LICENSE` notice.
It is a metadata identifier, not a new license or a grant of additional rights.

Commit `e36859a5342917535d9ab51c591a8a9060f30513` replaced the earlier MIT
notice with PolyForm Strict 1.0.0 for software and implementation assets, and
All Rights Reserved for project-authored non-software content unless otherwise
stated. That commit changed only `LICENSE`; the old MIT package label remained.
This correction removes that stale label without editing the notice. The notice
also preserves rights granted for earlier revisions and file-specific exceptions.

The full notice is deliberately retained: a short SPDX label must not erase its
different scopes. Build consumers should inspect the included license file and
any applicable file-specific terms. This metadata change does not resolve legal
questions about a particular intended use and does not authorize a release.
